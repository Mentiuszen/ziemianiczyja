# v0.4 — zatwierdzony zakres

Specyfikacja wykonawcza zatwierdzonego w rozmowie zakresu; rozszerzona o zgłoszony
problem Firefoksa: obrót kamery musi działać także przy trzymanym PPM i LPM+PPM.

## Cel
Przebudować istniejącą misję Cambrai, nie dokładać kolejnych map. Odprawa w budynku,
napisy bez dubbingu, aktywne posterunki przed szturmem, większy udział gracza,
funkcjonalne Mark IV, niemieckie działa 7,7 cm, ograniczone lotnictwo obu stron,
limit renderowanych FPS, naprawa schodkowania płotów i szczelne stosy worków.

## Architektura
- Jedyny właściciel czasu: Simulation / FixedClock. Dialog, limity, samoloty,
  artyleria, amunicja i wydarzenia misji mają stan odtwarzany przez checkpoint.
- Director prowadzi odprawę i kolejne cele; NPC samodzielnie wykonują zadania.
- Tank, field-gun i air-support są osobnymi modułami symulacji. Wspólne kolizje
  i obrażenia. Nie tworzymy dekoracyjnych wybuchów z ukrytymi obrażeniami.
- Renderowanie jest ograniczane przez FrameLimiter, nie przez spowalnianie AI.
- Sterowanie: Pointer Events dla ruchu i przycisków, Mouse Events tylko jako
  fallback ruchu dla przeglądarek bez Pointer Events. Bez podwajania delty.
- Nowe zasoby autorskie GLB; grafika retro, limity efektów zależne od presetów.

## Reguły
Statyczny build HTTP/HTTPS, lokalne zależności, WebGL2, polski interfejs.
Nie obiecujemy wyłączenia synchronizacji przeglądarki; opcja 0 = brak limitu gry.
Nie dodajemy A7V ani Tankgewehr do 20 listopada 1917. Niemiecka artyleria jest
odpowiedzią na Mark IV. Przeloty są fikcją lokalnego epizodu, nie rekonstrukcją.
Zabici NPC nie wracają do życia. Straty od sojuszników zaliczają cele. Brak hard
capu zabójstw, nieśmiertelności botów i nieskończonych fal. Stare checkpointy
odrzucamy czytelnym komunikatem; ustawienia pozostają.
Pracujemy w kopii archiwum; nie dotykamy repozytorium, branchy ani hostingu.
