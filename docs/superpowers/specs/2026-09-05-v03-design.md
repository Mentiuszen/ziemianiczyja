# Ziemia Niczyja v0.3 — approved implementation scope

Basis: user-approved nine-point v0.3 scope in the conversation, following v0.2 archive.
Work is in a new extracted delivery directory. No user repository, branch or worktree is changed.

## Systems
1. Fix native mesh winding (reproduced on crates, table and masonry). Keep glTF's own RH
   convention separate; keep exterior culling enabled, do not hide the defect with double-sided walls.
2. One authoritative static collider layout + spatial grid; living NPC body collision with self
   exclusion, allied yielding, substeps against tunnelling. Rendering quality never changes physics.
3. Expanded height field 216 x 272 m, playable rear/side approaches, north sector moved 40 m,
   extra support trenches, lanes, blasted orchard and ruined farm buildings with actual openings.
   Keep Cambrai's six objectives; mission version 2 deliberately rejects incompatible old checkpoints.
4. Original tileable surface colour/normal/roughness maps, tuft cutouts, terrain-aware road/puddles,
   better masonry silhouettes, sandbags, timber props and weapon GLBs. No copied game assets.
5. Three stable appearances per faction, shared atlas, existing 19-bone rig and three LODs per appearance.
   New first-person SMLE/Gewehr/Webley/Lewis and hands, with correct opaque depth rendering.
6. Low/Medium/High/Ultra centralized profiles control shadow size/range/filter, normal maps,
   anisotropy, cosmetic detail, LOD and bounded effects. NPC counts/AI/damage never change.
7. Grenade flash, dust, smoke, dirt fragments, short-lived ground mark and distance-scaled camera
   impulse. Cosmetic event randomness is separate from simulation RNG; finite pools are disposed.
8. Hit direction, injury vignette, critical-health pulse, slight desaturation and optional intensity.
   Simulation time drives decay; pause freezes state. Centre stays readable.
