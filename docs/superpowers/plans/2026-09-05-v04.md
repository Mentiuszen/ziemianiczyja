> For agentic workers: use superpowers:executing-plans; implementation in an isolated
> archive copy, not a Git branch/worktree. User approved implementation in this turn.

**Goal:** Deliver a playable v0.4 of Cambrai including the approved mission redesign.
**Architecture:** Simulation owns state. Director sequences goals; vehicles and aircraft
own their motion/fire; rendering mirrors state. Input and render scheduling are isolated.
**Tech Stack:** ES modules, Babylon.js 8.46.2 vendored, Node >=20, Python asset tools.
**Spec:** `docs/superpowers/specs/2026-09-05-v04-design.md`.

## Global constraints
WebGL2 and static hosting. No new branches or worktrees. No external runtime services.
No VSync promise, no anachronistic German tanks for Cambrai 1917. No fake test claims.
