# v0.3 Implementation Plan

> **For agentic workers:** use executing-plans inline, test and inspect each stage.

**Goal:** Deliver the approved v0.3 upgrade of the existing Cambrai FPS.
**Architecture:** Preserve Simulation/GameView separation; pure geometry/preset/feedback helpers;
shared authored layout and indexed colliders, original generated GLBs, bounded cosmetic effects.
**Tech Stack:** JavaScript ES modules, local Babylon.js 8.46.2, Node tooling, Python asset generators.
**Spec:** docs/superpowers/specs/2026-09-05-v03-design.md

## Global constraints
No new branches/worktrees, no remote publication, static HTTP/HTTPS deployment. Rendering
presets do not alter combat rules or opponent count. Report limitations rather than inventing tests.
